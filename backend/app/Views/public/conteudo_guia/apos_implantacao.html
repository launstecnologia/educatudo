Os 14 passos acima acontecem uma vez. A ficha do aluno é o lugar de tudo o que é dele. Os dois ciclos abaixo se repetem o ano inteiro.

Toda semana
Rotina
Avaliação → nota lançada → diário e frequência. É o que alimenta todo o resto: sem nota lançada, não há boletim nem ata.
A cada bimestre
Fechamento
Conferir → fechar → conselho → homologar → emitir. É aqui que sai a ata, o boletim e, no fim do ano, o histórico.
