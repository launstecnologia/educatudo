# Doc do sistema

Pasta de documentação viva do EducaTudo (Markdown).

## Wiki no navegador

### Master
- Índice: `/master/documentacao`
- Menu lateral + botão **Documentação** no topo

### Admin escola (`dev` / `diretor` / `coordenador`)
- Índice: `/admin/doc-sistema`
- Menu **Doc do sistema**

Cada arquivo `*.md` (exceto `README.md`) vira uma página automaticamente.

## Páginas iniciais

| Arquivo | Tema |
|---|---|
