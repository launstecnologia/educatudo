1. Visão geral do boletim SM

O print do Colégio Santa Maria organiza o ano em dois semestres, cada um com dois bimestres (unidades). Em cada bimestre aparecem notas lançadas (PP, PU, CH, PE, FAL) e uma coluna calculada (MU). No fim do semestre entram REC e MS; no fim do ano, MA, PF, MF e Situação.

Ideia central: o professor lança PP, PU, CH, PE, FAL, REC, PF. O sistema calcula MU, MS, MA e MF com as fórmulas deste manual.

Observação impressa no boletim SM de referência:

O estudante que não atingir média semestral 7,0 (sete) deverá realizar a recuperação semestral.
MU = ((PP + PU) / 2) + PE

3. MU — Média da Unidade (bimestre)

3.1 Regra clássica do print SM

MU = ((PP + PU) ÷ 2) + PE

Em português: média de PP e PU, depois some o ponto extra.

PPPUPEContaMU
8,06,01,0((8+6)÷2)+18,0
7,07,00,0((7+7)÷2)+07,0
9,05,00,5((9+5)÷2)+0,57,5
Sem PP ou sem PU (traço), a MU clássica fica incompleta. Por isso a escola usa CH (2ª chamada) e, no EducaTudo, a função nota substituta ou média ( provas | substituta ).

3.2 MU com CH (2ª chamada)

MU = nota substituta ( PP , PU , CH ) + PE

Ou, equivalente com grupos:

MU = média ( PP , PU | CH ) + PE

A CH cobre só a primeira prova que faltar. Não é uma terceira nota “por cima”. Não coloque ÷ 2 de novo depois de nota substituta — a média já está dentro.

4. CH — detalhe da substituta

  • Último argumento de nota substituta (…) = substituta.
  • No média ( provas | CH ), o 2º grupo depois do | é a substituta.
  • Se PP e PU existem, CH é ignorada.

5. PJ / Projeto (opcional) + condição se

Algumas turmas/eventos têm Projeto (PJ) opcional: se o aluno lançou PJ, a média passa a dividir por 3 (PP, PU e PJ); se não lançou, continua ÷ 2. A CH continua só nas provas; PE continua fora.

MU = se ( PJ , média ( PP , PU | CH | PJ ) , média ( PP , PU | CH ) ) + PE

Leitura:

  1. se ( PJ , … ) — se tem nota em PJ, usa a 1ª conta; senão a 2ª. (Igual a PJ = verdadeiro.)
  2. Dentro de média ( ), o | separa papéis pela posição:
    • 1º = provas (PP, PU) — CH pode cobrir
    • 2º = substituta (CH)
    • 3º = opcional (PJ) — só se lançado; CH nunca cobre o PJ
  3. + PE — sempre soma depois.
Por que PJ fica depois do CH? Porque o 3º grupo do | é o opcional. Não é “avaliar o aluno antes da média”. Quem decide se tem PJ é o se ( ) de fora.

6. MS — Média do Semestre

Cada semestre tem duas unidades (duas MUs).

MS 1º = ( MU do 1º bim + MU do 2º bim ) ÷ 2
MS 2º = ( MU do 3º bim + MU do 4º bim ) ÷ 2
MU1MU2MS

7,07,07,0
5,09,07,0
Regra SM: se a média semestral for menor que 7,0, o aluno deve fazer a recuperação semestral (REC).

8. PF e MF — Prova Final e Média Final

PF é lançada (prova final / recuperação anual, conforme o layout). MF fecha o ano.

Padrão frequente no EducaTudo para “se tiver PF, soma com MA; senão fica MA”:

MF = se ( PF , MA + PF , MA )

Outra forma comum (média com recuperação / composição):

MF = média c/ rec ( MA , PF )

Sem PF → fica MA. Com PF → (MA + PF) ÷ 2.

MAPFse (PF, MA+PF, MA)média c/ rec (MA, PF)
7,0—7,07,0
6,08,014,0*7,0

* Se usar MA + PF, ajuste o valor máximo da coluna (ex.: 20) ou prefira média c/ rec / outra regra da escola. Confirme sempre a regra pedagógica impressa no boletim da unidade.

9. REC — Recuperação semestral

No quadro SM, REC aparece junto de cada semestre. Quando a MS fica abaixo de 7,0, o aluno faz a recuperação. No editor, use média c/ rec se a REC deve entrar só quando existir:

média c/ rec ( MS , REC )
  • Sem REC → fica a MS
  • Com REC → (MS + REC) ÷ 2

10. FAL — Faltas

FAL é lançamento de frequência. Não entra na média de PP/PU/MU. Aparece no boletim para vida escolar / frequência.

11. Do bimestre ao ano (fluxo)

  1. Bimestre: lança PP, PU, (CH), PE, FAL → calcula MU
  2. Semestre: duas MUs → MS; se MS < 7 → REC
  3. Ano: duas MS → MA; se preciso → PF → MF e Situação
Mapa rápido
PP + PU (+ CH) (+ PJ) + PE → MU
MU + MU → MS
MS + MS → MA
MA (+ PF) → MF

12. Como montar no EducaTudo

  1. Abra o evento de notas → passo de aparência / cálculo.
  2. Clique no bloco amarelo da coluna (ex.: MU).
  3. Use os chips (PP, PU, CH, PE, PJ…) e os sinais, ou peça no assistente em português.
  4. Fórmulas prontas úteis:
    • Média com nota substituta + depois + PE
    • Provas | substituta | opcional + PE e/ou Se lançou
  5. Confira a linha: deve bater com este manual.
  6. Salvar bloco. Pode ocultar PP/PU/CH/PE no print e deixar só MU — o cálculo continua.
Exemplos prontos no assistente / editor:
MU = nota substituta ( PP , PU , CH ) + PE MU = se ( PJ , média ( PP , PU | CH | PJ ) , média ( PP , PU | CH ) ) + PE MS = ( MU1 + MU2 ) ÷ 2 MA = ( MS1 + MS2 ) ÷ 2 MF = se ( PF , MA + PF , MA )
